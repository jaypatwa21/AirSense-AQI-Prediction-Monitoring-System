## 🚁 How to Add Drone Photos

1. Take clear photos of your drone setup
2. Save as PNG format (better quality for documentation)
3. Resize to ~1200x800 pixels for optimal display
4. Place in `/ScreenShot/` folder
5. Reference in README.md with: `![Image Name](./ScreenShot/filename.png)`

## 💡 Tips for Good Documentation Screenshots

- **Clear visibility**: Ensure text and UI elements are legible
- **High resolution**: Use 1200px width minimum
- **Good lighting**: For drone photos, shoot in natural daylight
- **Consistent naming**: Use descriptive, lowercase names with hyphens
- **File optimization**: Compress images to keep file sizes reasonable

## 🔄 Update README When Adding New Images

Once you add new images, update the README references:

```markdown
![Image Description](./ScreenShot/your-image.png)
```
